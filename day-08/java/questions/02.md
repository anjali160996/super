# Q02 — Same probes with virtual threads

**Continuation from Day 8 Q01** — reuse `ProbeTarget`, `ProbeResult`, and `probe(...)`.

Same workload, same 500 targets — swap the executor for virtual threads and compare wall time.

## Requirements

1. Keep `probe(ProbeTarget)` unchanged from Q01.
2. Implement `List<ProbeResult> checkAll(List<ProbeTarget> targets)` using **`Executors.newVirtualThreadPerTaskExecutor()`** (try-with-resources):
   - one task per target (no platform pool size cap)
   - results in **input order**
3. Demo in `main` with the **same 500 targets** as Q01. Print wall time and success count.

## Constraints

- Reuse Q01 types and `probe` — do not rename or duplicate them.
- Virtual-thread executor only — not `newFixedThreadPool`.

## Expected behavior

```text
checkAll(500 targets) → 500 results, all ok
// wall time noticeably lower than Q01 (~100–200 ms vs ~1–2 s)
```
