# Q02 — 3. Longest Substring Without Repeating Characters

Source: https://leetcode.com/problems/longest-substring-without-repeating-characters/description/

Given a string `s`, find the length of the **longest substring** without repeating characters.

## Examples

```text
Input:  s = "abcabcbb"
Output: 3
Explanation: The answer is "abc", with length 3.

Input:  s = "bbbbb"
Output: 1
Explanation: The answer is "b", with length 1.

Input:  s = "pwwkew"
Output: 3
Explanation: The answer is "wke", with length 3.
The substring "pwke" is not valid because 'w' repeats.

Input:  s = " "
Output: 1
```

## Constraints

- `0 <= s.length <= 5 * 10^4`
- `s` consists of English letters, digits, symbols, and spaces.

## Follow-up

- Sliding window with a `HashMap` or `HashSet`: expand right, shrink left when a duplicate appears.
- O(n) time, O(min(n, alphabet)) space.
