# Q02 — HttpClient: GET with timeout and status handling

The **`java.net.http.HttpClient`** API (Java 11+) replaces older `HttpURLConnection` for HTTP calls. Configure timeouts, send a request, and interpret status codes explicitly.

## Requirements

1. Build a reusable client once (static field or factory method):
   - `connectTimeout` of 3 seconds
   - follow redirects: `NORMAL`
2. Implement `HttpResult fetch(String url)` where `HttpResult` is a record:
   - `int statusCode`
   - `String body` — response body as string (may be empty)
   - `boolean success` — `true` when status is 2xx
3. `fetch` must:
   - `GET` the URL with `HttpResponse.BodyHandlers.ofString()`
   - use a **request timeout** of 5 seconds (`HttpRequest.Builder.timeout`)
   - not throw on 404/500 — wrap status + body in `HttpResult`
   - throw `IOException` only for network/timeout failures (let it propagate or document in signature)
4. Implement `String fetchBodyOrThrow(String url)` — returns body when `success`, else throws `IllegalStateException` with the status code in the message.
5. Demo in `main` against a public echo URL (e.g. `https://postman-echo.com/get`) and print status + first 80 chars of body.

## Constraints

- Use `java.net.http.HttpClient` / `HttpRequest` / `HttpResponse` — no third-party HTTP libraries.
- No Spring `RestTemplate` / `WebClient`.
- Invalid URL syntax may throw `IllegalArgumentException` from `URI.create` — that is fine.

## Expected behavior

```text
fetch("https://postman-echo.com/get")
// HttpResult[statusCode=200, body="...", success=true]

fetch("https://postman-echo.com/status/404")
// HttpResult[statusCode=404, body=..., success=false]

fetchBodyOrThrow("https://postman-echo.com/status/500")
// throws IllegalStateException mentioning 500
```

## Hint

```java
HttpClient.newBuilder()
    .connectTimeout(Duration.ofSeconds(3))
    .followRedirects(HttpClient.Redirect.NORMAL)
    .build();
```
