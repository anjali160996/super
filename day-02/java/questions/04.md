# Q04 — equals and hashCode together

Override `equals` and `hashCode` so a simple value type works as a `HashMap` key.

## Requirements

1. Implement immutable `Point` with `int x`, `int y`.
2. Override `equals` and `hashCode` so two points with the same `x` and `y` are equal and have the same hash.
3. Put one `Point` in a `HashMap` and look it up with a **different instance** that has the same coordinates.

## Constraints

- Use `Objects.equals` / `Objects.hash` (or equivalent field-based logic).
- Do not leave `hashCode` as identity hash while overriding `equals`.

## Expected behavior

```text
Map<Point, String> map = new HashMap<>();
map.put(new Point(1, 2), "A");

map.get(new Point(1, 2)) == "A"
map.get(new Point(0, 0)) == null
```
