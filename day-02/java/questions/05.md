# Q05 — try-with-resources for closeable I/O

Always close resources with try-with-resources so streams/files are closed even on exceptions.

## Requirements

1. Write a method `String readFirstLine(Path path)` that:
   - opens the file with `BufferedReader` (or `Files.newBufferedReader`)
   - returns the first line (or `null` / empty if the file is empty — pick one and stick to it)
2. Use **try-with-resources** so the reader is closed automatically.
3. In `main`, write a tiny temp file, call `readFirstLine`, print the result.

## Constraints

- Do not use a bare `open` + manual `close()` in a `finally` unless you also show try-with-resources as the preferred form.
- Propagate or wrap `IOException` as you like; just don't swallow it silently.

## Expected behavior

```text
// file contains:
// hello
// world

readFirstLine(path) → "hello"
// reader is closed after the call (no leaked handle)
```
