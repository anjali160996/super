# Q02 — Defensive copy on get/set

Keep internal collections from being mutated by callers.

## Requirements

1. Implement `Playlist` with:
   - `void setTracks(List<String> tracks)`
   - `List<String> getTracks()`
2. `setTracks` must store a **copy** of the incoming list (not the caller's list reference).
3. `getTracks` must return a **copy** or an unmodifiable view — callers must not be able to `add`/`remove` into your internal list.

## Constraints

- Do not expose a public mutable field.
- `List.copyOf` / `new ArrayList<>(...)` / `Collections.unmodifiableList` are all fine.

## Expected behavior

```text
List<String> input = new ArrayList<>(List.of("a", "b"));
Playlist p = new Playlist();
p.setTracks(input);

input.add("c");                 // must not change playlist
p.getTracks().add("d");         // must not change playlist (throw or copy)

// p.getTracks() == [a, b]
```
