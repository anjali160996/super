# Q03 — Build strings with StringBuilder

When appending in a loop, use `StringBuilder` instead of `String` `+`.

## Requirements

1. Implement `String join(List<String> parts, String delim)` that joins parts with `delim`.
2. Use a `StringBuilder` (or `StringJoiner`) inside the method — do not build the result with `result = result + ...` in a loop.
3. Empty list → `""`. No trailing delimiter.

## Constraints

- One pass over `parts` is enough.
- `String.join` is acceptable only if you also show the equivalent `StringBuilder` version (comment or second method).

## Expected behavior

```text
join(List.of("a", "b", "c"), ",")  →  "a,b,c"
join(List.of(), ",")               →  ""
join(List.of("only"), ",")         →  "only"
```
