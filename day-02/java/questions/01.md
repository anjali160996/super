# Q01 — Shallow clone vs deep clone

Implement shallow and deep cloning for a simple nested object.

## Requirements

1. Model:
   - `Address` — `city`, `zip`
   - `Person` — `name`, `Address address`
2. On `Person`, implement:
   - `Person shallowClone()` — new `Person`, but same `Address` instance as the original
   - `Person deepClone()` — new `Person` **and** new `Address` (copy of fields)
3. Demo in `main`: change `clone.getAddress().setCity(...)` and show shared vs independent behavior.

## Constraints

- Explicit copy / copy-constructor style is fine (no need for `Cloneable` / serialization).
- Deep clone must not share the `Address` reference with the original.

## Expected behavior

```text
Person original = new Person("Ada", new Address("Pune", "411001"));

Person shallow = original.shallowClone();
shallow.getAddress().setCity("Mumbai");
// original.getAddress().getCity() == "Mumbai"  // shared

Person original2 = new Person("Ada", new Address("Pune", "411001"));
Person deep = original2.deepClone();
deep.getAddress().setCity("Mumbai");
// original2.getAddress().getCity() == "Pune"   // independent
```
