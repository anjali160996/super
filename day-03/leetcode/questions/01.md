# Q01 — 189. Rotate Array

Source: https://leetcode.com/problems/rotate-array/description/

Given an integer array `nums`, rotate the array to the right by `k` steps, where `k` is non-negative.

## Examples

```text
Input:  nums = [1,2,3,4,5,6,7], k = 3
Output: [5,6,7,1,2,3,4]
Explanation: rotate 1 step → [7,1,2,3,4,5,6]
             rotate 2 steps → [6,7,1,2,3,4,5]
             rotate 3 steps → [5,6,7,1,2,3,4]

Input:  nums = [-1,-100,3,99], k = 2
Output: [3,99,-1,-100]

Input:  nums = [1,2], k = 3
Output: [2,1]
Explanation: k = 3 is equivalent to k = 1 when length is 2.
```

## Constraints

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

## Follow-up

- Do it **in-place** with O(1) extra space.
- Handle `k >= nums.length` by using `k % nums.length`.
- Prefer O(n) time (reverse segments, cyclic replace, or similar) — avoid rotating one step at a time in O(n * k).
