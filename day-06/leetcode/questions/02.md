# Q02 — 347. Top K Frequent Elements

Source: https://leetcode.com/problems/top-k-frequent-elements/description/

Given an integer array `nums` and an integer `k`, return the **k most frequent elements**. You may return the answer in **any order**.

## Examples

```text
Input:  nums = [1,1,1,2,2,3], k = 2
Output: [1,2]

Input:  nums = [1], k = 1
Output: [1]
```

## Constraints

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `k` is in the range `[1, number of unique elements in nums]`
- It is **guaranteed** that the answer is unique

## Follow-up

- Count frequencies with a `HashMap`, then pick top `k` (bucket sort by frequency, or a min-heap of size `k`).
- Aim for better than O(n log n) if you use buckets: O(n) time, O(n) space.
