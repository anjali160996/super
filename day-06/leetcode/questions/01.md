# Q01 — 217. Contains Duplicate

Source: https://leetcode.com/problems/contains-duplicate/description/

Given an integer array `nums`, return `true` if any value appears **at least twice** in the array, and return `false` if every element is distinct.

## Examples

```text
Input:  nums = [1,2,3,1]
Output: true
Explanation: 1 appears twice.

Input:  nums = [1,2,3,4]
Output: false

Input:  nums = [1,1,1,3,3,4,3,2,4,2]
Output: true
```

## Constraints

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## Follow-up

- O(n) time with a `HashSet` (add each value; return true on duplicate).
- Sorting also works but is O(n log n) — set lookup is simpler here.
