# Q04 — Interface default and static methods

Java 8 lets interfaces ship **default** instance methods and **static** helpers without breaking existing implementers. Useful for small plugin-style APIs.

## Requirements

1. Define `interface ReportSection` with:
   - `String title()` — implementers must supply
   - `default String render()` — returns `title() + ": (empty)"`
   - `static ReportSection titled(String title)` — returns an anonymous implementation where `title()` returns the given string and `render()` uses the default body
2. Define `class SalesSection implements ReportSection`:
   - Constructor takes `title` and `double total`
   - Override `render()` → `title() + ": total=" + total` (two decimal places OK)
3. Implement `String buildReport(List<ReportSection> sections)` — join each section's `render()` with newline (`"\n"`).
4. Demo in `main` with one `SalesSection` and one section from `ReportSection.titled("Notes")`.

## Constraints

- Use both a **default** method and a **static factory** on the same interface.
- Do not use an abstract class for the empty section — use the static factory + default method.
- `buildReport` must preserve section order.

## Expected behavior

```text
sections = [
  new SalesSection("Q1", 12500.5),
  ReportSection.titled("Notes")
]

buildReport(sections)
// Q1: total=12500.5
// Notes: (empty)
```
